Gizlilik Politikası – "Yorum Ajani"

Son güncelleme: 20 Kasım 2026

"Yorum Ajani", yalnızca @NuraySaglamBedir YouTube kanalının sahibi tarafından, kendi kanalındaki videolara yazılan herkese açık yorumları okumak ve kanal sahibinin onayladığı cevapları göndermek için kullanılan kişisel bir uygulamadır. Başka kullanıcılar bu uygulamaya giriş yapmaz.

Hangi veriler kullanılır?

Yalnızca YouTube Data API üzerinden kanalın videolarına yazılmış herkese açık yorumlar (yorum metni, yazan kişinin herkese açık kanal adı, tarih) okunur. Bu veriler yalnızca yoruma cevap hazırlamak ve öğrencilerin en çok sorduğu konuları özetlemek için kullanılır.

Paylaşım ve saklama

Veriler satılmaz, reklam için kullanılmaz ve üçüncü kişilerle paylaşılmaz. Kişisel veri toplanmaz; yalnızca cevap taslakları için gereken yorum metinleri kısa süreli işlenir.

Google API Hizmetleri

Uygulamanın Google API'lerinden aldığı bilgileri kullanımı, Sınırlı Kullanım (Limited Use) koşulları dahil Google API Services User Data Policy'ye uygundur.

İletişim

Sorularınız için kanal üzerinden ulaşabilirsiniz: youtube.com/@NuraySaglamBedir

Privacy Policy (English)

"Yorum Ajani" is a personal app used only by the owner of the @NuraySaglamBedir YouTube channel to read public comments on the channel's own videos and to post replies the owner has approved. It reads public comment data via the YouTube Data API solely for that purpose. Data is not sold, not used for advertising and not shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: via the YouTube channel.
