# 001 — Akım, gerilim, direnç nedir ve aralarında nasıl bir ilişki vardır?

## Gerekli bilgi listesi (videoda geçtiği yer)
- [x] Akım: telde akan elektrik yükü; saniyede geçen yük miktarı (a1, a2)
- [x] Yük birimi kulon; 1 A = 1 C/s; I = Q/t (a3)
- [x] Akımın harfi I, birimi amper; miliamper = amperin binde biri (a4, o4)
- [x] Gerilim: yükleri harekete geçiren itme gücü (pil); büyük gerilim = güçlü itme; V, volt (g1–g3)
- [x] Direnç: akışa gösterilen engel; yükler çarpar/zorlanır; R, ohm (d1–d3)
- [x] Ohm yasası: V = I × R ve I = V / R (o1–o3)
- [x] Gerçek değerli örnek: 9 V / 450 Ω = 20 mA (o4)
- [x] Gerilim 2 katı → akım 2 katı (o5); direnç 2 katı → akım yarısı (o6); genel kural (o7)
- [x] Özet (s1, s2)
