# 007 — zor noktalar (bölüm 2f)
(a) Öğrencilerin zorlandığı noktalar (Razavi Ders 2):
1. Akım kaynağı pil gibi "açık bırakılabilir" sanılır; ideal akım kaynağı açıkken V = i·R → ∞ gerekir [49:30–50:35]. (vurgulanan yanlış)
2. Gerilim kaynağının akımı kendisi belirlemez; akım yüke bağlıdır (i = V/R) [14:02].
3. V sabitken i–R ilişkisi doğrusal değildir (i ∝ 1/R); öğrenciler doğrusal bekler.
4. İdeal modelin sınırı: R → 0'da gerçek pilin gerilimi düşer [14:52].
(b) Ön bilgi: Ohm yasası (V = I·R); ideal eleman kavramı; açık devre ⇔ R → ∞.
